Calculator Promo Apple — Google Sheets Live

Files:
- index.html : calculator, still includes fallback data but uses live Google Sheets when configured.
- Code.gs : Google Apps Script endpoint that reads the Google Sheet directly.
- README-Google-Sheets-Live.md : detailed setup instructions.

Important: the HTML cannot know your Google Sheet URL until you deploy Code.gs and paste the resulting /exec URL into ADMIN > Google Sheets Web App URL.
